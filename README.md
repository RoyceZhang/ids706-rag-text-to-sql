# IDS 706 Week 8: RAG-Powered Text-to-SQL

For this project, I extended my Week 7 SQL Quiz application with a RAG feature. A user can ask a question about the store database in plain English and get a PostgreSQL query.

## How it works

The app follows this workflow:

1. The user enters a natural-language question.
2. ChromaDB searches a vector collection for relevant database schema details and example questions with SQL.
3. The app sends the question and retrieved context to the OpenAI Responses API using `gpt-5-mini`.
4. The app displays the generated PostgreSQL query.

The ChromaDB collection contains descriptions of the `customers`, `products`, and `orders` tables, their relationships, and example SQL queries. The app retrieves the three closest documents for each question and shows them under **Retrieved context**.

The Week 7 quiz is still included. It connects to the hosted Supabase PostgreSQL database, lets signed-in users run read-only queries, and saves quiz answers. Generated SQL from the RAG section is displayed for review; it is not run automatically.

## Tools used

- Streamlit for the web app
- Supabase for PostgreSQL and user authentication
- ChromaDB for vector storage and retrieval
- OpenAI API for SQL generation

## Run locally

You will need Python 3.12, a Supabase project, and an OpenAI API key.

1. Clone this repository and enter the project folder:

   ```bash
   git clone https://github.com/RoyceZhang/ids706-rag-text-to-sql.git
   cd ids706-rag-text-to-sql
   ```

2. Create and activate a virtual environment, then install the packages:

   ```bash
   python3.12 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   ```

   On Windows PowerShell, activate it with `.venv\\Scripts\\Activate.ps1`. In Command Prompt, use `.venv\\Scripts\\activate.bat`.

3. Copy the example secrets file and add your own credentials:

   ```bash
   cp .streamlit/secrets.toml.example .streamlit/secrets.toml
   ```

   The secrets file needs these settings:

   ```toml
   supabase_url = "YOUR_SUPABASE_URL"
   supabase_publishable_key = "YOUR_SUPABASE_PUBLISHABLE_KEY"
   db_host = "YOUR_SUPABASE_POOLER_HOST"
   db_port = 5432
   db_user = "quiz_reader.YOUR_PROJECT_REF"
   db_password = "YOUR_QUIZ_READER_PASSWORD"
   db_name = "postgres"
   openai_api_key = "YOUR_OPENAI_API_KEY"
   ```

4. Start the app:

   ```bash
   python -m streamlit run app.py
   ```

   Open http://localhost:8501 in your browser.

## Deploy

The app is deployed with Streamlit Community Cloud from the `main` branch of this repository, using `app.py` as the entry point. The same settings from the secrets example are added in the app's **Settings → Secrets** page.

## Notes

- The generated SQL is an AI-generated suggestion and may need changes before use.
- The RAG feature displays SQL but does not execute or automatically validate it.
- Keep your real `.streamlit/secrets.toml` private. It is listed in `.gitignore` and should not be committed.
